## 便宜的前提：线路走得对不对

欧洲机房到国内的物理距离摆在那里，光速决定了延迟下限。普通德国 VPS 走的是电信 163 骨干网（AS4134）、联通 AS4837、移动 CMI，平时还能用，一到晚高峰就开始绕路和丢包。CN2 GIA 走的是电信下一代承载网（AS4809，路由里能看到 59.43 节点），专门为高质量业务设计，高峰期不挤在同一条拥堵链路上。

AkkoCloud 法兰克福机房的做法是去程各走各的最优路径，回程统一收口到精品网：电信、联通双向 CN2 GIA，移动去程 CMI 直连、回程 CMIN2。回程这一段对国内访问体验影响最大，因为下载和 SSH 回显都走回程。联通去程究竟是 GIA 还是 AS4837，不同来源说法不一致，用官方 Looking Glass 跑一次路由追踪就能看到实际路径。

延迟数字方面，公开测评给出的区间是国内多地 160–182ms，多数落在 177ms 上下，电信和联通大致 170ms 出头，移动稍高一些，晚高峰没有出现断崖式抖动。作为对照，普通欧洲直连线路普遍在 220ms 以上，动辄 250ms 以上也不少见。要强调的是，这些是第三方作者在自己线路上跑出来的结果，不同省份、不同运营商差异不小，不能当成官方 SLA。

## 哪些套餐多数人用不上

**512MB 内存能干的和干不了的**

299 元/年的 A1 mini 是全网最便宜的入门价，但 512MB 内存有明确边界。跑一个精简的 Debian、做代理节点、SSH 跳板、监控探针、定时任务，这些没问题。跑 WordPress 就要配 swap，PHP 插件一多、后台一开批量操作就容易吃紧；Docker 跑一两个小容器还行，多容器编排基本别想。想“装完就不用管”的建站需求，直接看 699 元档的 B1 mini，1GB 内存 + 20GB SSD + 1.2TB 月流量是这个用途的起步配置。

**不限流量系列**

1200 元/月起步、带宽 30Mbps，只适合视频中转、大文件分发、高流量代理这类“流量比速度重要”的场景。个人用户买它是纯浪费。

**四条只写在条款里的限制**

- **不允许退款**。官方 Tos 明确写了不退款，这和很多 VPS 商家不一样。先用季付或月付试水，比事后扯皮划算。

- **流量双向计算**。上传和下载都计入月流量配额，备份、同步、网盘类业务要把上传侧算进去，别只盯下载。
- **季付是限量款**。99 元/季和 149 元/季属于偶尔上架的限量特惠，售完即止，不是常态在售。
